# تطبيق الهاتف (Flutter)

تطبيق Android و iOS يتصل بنفس واجهة المنصة البرمجية (افتراضياً `https://nalut.abade.ly`، ويمكن تغيير
الخادم من شاشة الدخول).

## ما يتضمنه
- تسجيل الدخول بالبريد أو الهاتف مع رمز المصادقة الثنائية؛ رمز التحديث محفوظ في التخزين الآمن للنظام
  (Keystore / Keychain) ويُدوَّر في كل تجديد.
- الرئيسية: مهام قريبة، محاضرات اليوم، نسب الغياب، مؤشرات تحتاج الاهتمام.
- المهام: القائمة، التفاصيل، رفع الملفات من الهاتف، مسودة/تسليم نهائي، عرض الدرجة والملاحظات بعد نشرها.
- الحضور: مسح QR الديناميكي، الرمز الرقمي البديل، صورة حية من الكاميرا الأمامية (بدون معرض الصور)،
  الموقع عند الطلب، معرّف جهاز عشوائي لكل تثبيت، وسجل الحضور ونسب الغياب. للموظفين: دخول/انصراف.
- الإشعارات (مع عداد غير المقروء)، الرسائل مع الإبلاغ، الدرجات الرسمية المنشورة.
- أعضاء هيئة التدريس والإدارة: الحضور والإشعارات والرسائل، وزر لفتح لوحة التحكم على الويب.

## الحصول على ملف APK
كل تعديل على مجلد `mobile/` يبني التطبيق تلقائياً على GitHub:
**Actions ← mobile app ← آخر تشغيل ناجح ← Artifacts ← `nalut-university-apk`**.
لبناء نسخة لخادم آخر: Actions ← mobile app ← Run workflow ← أدخل عنوان الخادم.

النسخة الحالية موقعة بمفتاح تطوير، وتصلح للتثبيت المباشر والتجربة (يطلب Android السماح بالتثبيت من مصادر غير معروفة).
للنشر في Google Play يلزم مفتاح توقيع خاص بالجامعة.

## البناء محلياً
```bash
cd mobile
flutter pub get
flutter test
flutter run                                   # على هاتف موصول أو محاكي
flutter build apk --dart-define=SERVER_URL=https://nalut.abade.ly
```
iOS يتطلب جهاز Mac مع Xcode وحساب Apple Developer.

## الاختبارات
- `test/api_client_test.dart`: حفظ الرموز، التجديد التلقائي، الأخطاء.
- `test/app_test.dart`: الدخول والوصول للرئيسية بواجهة عربية RTL.
- `test/contract_test.dart`: نفس شيفرة التطبيق ضد خادم حقيقي (الدخول، البيانات، تسجيل الحضور بالـ QR، رفع ملف):
  `NUS_TEST_SERVER=http://127.0.0.1:8000 flutter test test/contract_test.dart`

## لاحقاً
- الإشعارات الفورية (Firebase Cloud Messaging): تتطلب مشروع Firebase للجامعة وملف `google-services.json`؛
  التطبيق يرسل رمز الجهاز إلى `/api/me/devices` والخادم جاهز لذلك.
- مفتاح توقيع للنشر في المتاجر، وأيقونة وهوية الجامعة.
