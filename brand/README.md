# الهوية البصرية ومواد العرض

| الملف | ما هو | للطباعة |
|---|---|---|
| `out/identity.pdf` | دليل الهوية البصرية (9 صفحات A4 أفقي) | للعرض والمشاركة |
| `out/rollup.pdf` | ستاند رول أب 85×200 سم | جاهز للمطبعة: 860×2010 مم (5 مم زيادة قص من كل جهة) |
| `out/brochure-outside.pdf` | المطوية: الوجه الخارجي | A4 أفقي مع 3 مم زيادة قص (303×216 مم) |
| `out/brochure-inside.pdf` | المطوية: الوجه الداخلي | يُطبع على ظهر الخارجي، قلب على الحافة الطويلة |
| `out/logo.pdf` و`logo/*.png` | الشعار بصيغه (أفقي وعمودي، فاتح وداكن) بخلفية شفافة | — |
| `logo/*.svg` | الرمز بصيغة متجهة (ملون، على داكن، أبيض، أسود) | — |

العرض التقديمي (14 شريحة) في Claude باسم «منصة الجامعة الذكية — عرض المشروع»، ويُنزَّل منه PowerPoint أو PDF.

## ملاحظات للمطبعة
- **الرول أب:** أسفل التصميم (نحو 15 سم) يدخل في قاعدة الستاند ولا يحتوي محتوى مهماً. القياس النهائي 85×200 سم.
- **المطوية:** طي ثلاثي للداخل، وتُقرأ من اليمين لليسار. خطوط الطي من الحافة اليسرى للورقة المقصوصة:
  الوجه الخارجي عند 100 و200 مم (الغلاف يسار، الظهر في الوسط، الجناح الداخلي 97 مم يمين)،
  والداخلي عند 97 و197 مم. ورق مقترح: 170 جم مطفي (Matt).
- الملفات بألوان RGB؛ قيم CMYK التقريبية في دليل الهوية (صفحة الألوان). اطلب بروفة لونية قبل الكمية.
- النصوص متجهة والخطوط مضمّنة في ملفات PDF، واللقطات من المنصة نفسها بدقة عالية.

## التعديل وإعادة التوليد
المصادر في `src/` (HTML وCSS). بعد أي تعديل:
```
npm i playwright && npx playwright install chromium   # مرة واحدة
node brand/render.js                                   # أو اسم تصميم واحد: node brand/render.js rollup
```
الخطوط (Cairo وIBM Plex Sans Arabic) في `fonts/` برخصة SIL المفتوحة.
